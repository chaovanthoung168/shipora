<h1 align="center">Shipora</h1>

<p align="center">
  Shipora is a self-hosted application deployment platform designed to connect GitHub repositories and manage projects and deployments on your own servers. Built for Docker Compose, it brings your deployment workflow into one dashboard while keeping your infrastructure and data under your control.
</p>
